## 1.0.0

First stable release.

* Design tokens: colors, typography scale, spacing, and border radius.
* Light and dark `ThemeData`, with the tokens exposed as theme extensions.
* Components: `RGAvatar`, `RGButton`, `RGCheckbox`, `RGDialog`, `RGDivider`,
  `RGEmptyState`, `RGListRow`, `RGNavItem`, `RGPasswordField`, `RGSectionHeader`,
  `RGSelect`, `RGSidebar`, `RGSocialButton`, `RGSwitch`, `RGText`, `RGTextField`.
* Widgetbook catalog published to GitHub Pages, grouped by category.
* Widget tests for behaviour and golden tests for appearance, both light and
  dark, generated and verified inside a pinned Flutter image.
* Social preview meta tags on the published catalog.

## 0.0.1

* Initial project scaffold for the RG Design System.
